# Java MOOC Learning Journey ☕

Collection of Java exercises, solutions, and small projects while following the Java Programming MOOC course.

The goal of this repository is to track my progress, practice Java fundamentals, and build stronger programming skills through hands-on exercises.

## Repository Structure

The repository is organized into packages, with each package representing a part of the Java MOOC course.

Each part contains the classes and exercises covered throughout that section of the course, making it easy to follow my progress and see what I have learned along the way.

## Contents

- Java MOOC course exercises
- Additional practice problems
- Small projects and challenges
- Experiments with Java concepts


This repository is a personal learning log where I document my progress and improvements while learning Java.
